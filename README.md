# Fare splitter

A simple command-line Python program to calculate fares for journeys and split it among the passengers based on their individual distances traveled.

## Features

- **Total Fare Calculation**: Calculate the total fare based on per KM rate and distance.
- **Fare splitting**: Option to split fare among 2 to 4 passengers.
- **Break down distance-wise:** Split the cost based on individual distance traveled by each passenger and allocate the rest automatically to last passenger.
- **Currency formatting:** Display all amounts in proper currency format up to two decimal places.

## Dependencies

- [Python 3.x](https://www.python.org/downloads/)
